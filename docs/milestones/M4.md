## Built

- **Reply judge** (`app/eval/judge.py`): "would the mentor send this unchanged?", run only where the
  agent made the mentor's decision. Claude (`claude-opus-5-5`, cached system prompt) when a key is
  set; an offline word-overlap judge otherwise. A missing draft is never acceptable. Agreement
  now needs the decision, the observed critical fields, and an acceptable reply.
- **Teaching queue** (`app/learning/teaching.py`): disagreements, then cases the intern was unsure
  of (under 70%), then spot checks. Agreements are counted, not reviewed.
- **Lessons**: the brief's four buttons. "Intern wrong" counts as its error. "Both fine" counts as
  agreement. "I'd change my call" takes the case out of the score. "Intern couldn't have known"
  marks a should-have-handed-back case. Optional why, optional reply verdict, optional "make this a
  rule". Notes become case memory the agent sees on later similar cases, but only after the note
  was written.
- **Rules** (`app/learning/rules.py`): inferred from decided history (Claude with lessons, or
  offline: phrases that lead to one decision at least 90% of the time, at least 5 cases). Rules
  are proposed, then accepted, edited, retired or written by the mentor. An edited rule becomes
  the mentor's. Without a key, the offline agent can apply simple plain-English rules (it reads
  the decision named and the quoted phrase).
- **No leaks through rules**: a rule is never used on its own example cases, and an inferred rule
  only on cases that arrived after all its evidence. The time-travel guard checks both.
- **Re-prediction runs** reuse the backtest runner with explicit cases and one sample per case, and
  record what changed against each case's previous prediction.
- **Web**: Today (summary and one teaching card at a time) and What I've learned (rules by status,
  examples, inline edit, live re-prediction result).

## Demo

With M3's history loaded and a backtest run: open **Today** as the invoice mentor and teach a few
cards. Open **What I've learned**, choose "Find rules in my decisions", accept one, then edit it
and watch the backlog re-prediction report what changed.
