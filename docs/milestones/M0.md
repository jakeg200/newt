# M0 — Skeleton

**Status:** done 2026-10-17. Acceptance: tests run in one command (`python -m pytest`, 21 passing);
both synthetic task types load from config, and a third config dropped into the folder loads with no
code change (`test_new_task_type_needs_no_code_change`).

## Built

- Repo docs: CLAUDE.md, BRIEF.md, PLAN.md, docs/DECISIONS.md, docs/NEEDS_JAKE.md.
- `backend/app/models.py`: all 20 tables from the brief's data model, portable across SQLite and
  Postgres; `orgs.is_synthetic` flags synthetic data.
- `backend/migrations/`: Alembic, initial migration `0001`; a test checks migrations create exactly
  the model's tables.
- `backend/app/task_types.py`: strict config schema (unknown keys, single-option decisions, bad α,
  unknown actions all rejected), loader, stable config hash for versioning.
- `task_types/`: invoice mismatch (accounts payable) and tenant repair request (property management).
- `backend/app/auth.py`: dev auth via `X-Dev-User`, refused outside `ENV=dev`; `require_role`.
- `backend/app/seed.py`: idempotent synthetic org — manager, a mentor per task type, built-in
  agent, apprenticeships, 40 backtest cases with mentor decisions per task type.
- API: `/health`, `/task-type-configs`, `/me`, `/task-types`.

## Demo

```
cd backend
.venv\Scripts\python -m alembic upgrade head
.venv\Scripts\python -m app.seed
.venv\Scripts\python -m uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs.
